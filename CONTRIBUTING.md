# Contributing

Thank you for your interest in the Hebrew Idiom Detection project.

## Reporting Issues

If you encounter bugs or have questions, please [open an issue](https://github.com/igornazarenko434/hebrew-idiom-detection/issues) with:
- A clear description of the problem
- Steps to reproduce (if applicable)
- Your Python/PyTorch version and hardware

## Dataset Contributions

The **Hebrew-Idioms-4800** dataset is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). If you'd like to:
- Report annotation errors or inconsistencies
- Suggest additional idioms for future versions
- Extend the dataset with new sentences

Please open an issue with the `dataset` label.

## Code Contributions

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Follow existing code style (Python, type hints where present)
4. Ensure tests pass: `python -m pytest tests/`
5. Submit a pull request with a clear description

## Code Style

- Python 3.10+
- Follow existing patterns in `src/` and `scripts/`
- Use descriptive variable names
- Add docstrings for new public functions
